# TextDrawing — раздел 6 «Использование доменов приложения»

Откройте TextDrawing.sln в Visual Studio и назначьте TextDrawing стартовым проектом.
Требуется .NET Framework 4.7.2. Соберите решение и запустите его (F5).

В решении три проекта: TextDrawing (запуск), TextWindow (ввод текста), TextDrawer (отрисовка).
Введите текст в верхнем окне: нижнее немедленно отобразит его коричневым цветом.
Меню Font открывает выбор шрифта (по умолчанию Arial, 45).
При перемещении верхнего окна нижнее следует за ним. Нижнее окно можно менять в размерах.
Закрытие TextWindow завершает оба окна, выгружает оба домена и показывает уведомление DomainUnload для Drawer.
Оба оконных exe также можно запустить отдельно; связь между ними создаёт стартовый проект.

В отличие от опечаток в примере PDF, объекты действительно создаются внутри разных AppDomain через CreateInstanceFromAndUnwrap.
MarshalByRefObject обеспечивает междоменное взаимодействие, BeginInvoke передаёт изменения в поток окна.
Каждое окно создаётся и работает в собственном STA-потоке. Рисование выполняется через Paint/Invalidate с освобождением GDI-ресурсов.
